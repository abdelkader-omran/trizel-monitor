# iOS App Boundary — TRIZEL Scientific Monitor

## Purpose
The iOS app is a read-only Capacitor wrapper around static local site content under `site/`.

## Scope
- Displays bundled local pages for:
  - Status
  - Agencies & observatories
  - Records
  - Snapshots
  - Policies
  - Build metadata (`site/build.json`)
- Provides offline-safe navigation between bundled pages.

## Out of Scope
- No scientific execution logic.
- No data ingestion, analysis, or automation workflows.
- No direct communication features.
- No upload, submission, payment, or transactional features.

## App Store Safety Notes
- Neutral informational wording only.
- No placeholder branding fields.
- No superiority, validation, rewards, or benchmark claims in app UI.
- Content is informational and non-operational.

## Platform Configuration
- App name: `TRIZEL Scientific Monitor`
- Bundle ID: `com.trizel.monitor`
- Version: `1.0`
- Build number: `1`
